
# 📌 IPSAT App For Everyone 📌

*IPSAT BETA is a modern mobile application designed for streaming movies and TV series. The platform provides users with an intuitive interface to explore, watch, and manage their favorite content. The app is currently in its beta phase, allowing users to experience new features before the official release.*

<img width="1920" alt="Cover" src="https://github.com/user-attachments/assets/ff981890-2ded-41fd-9307-d7ac21eb7c05" />

### 🎬 Features
- **User-Friendly Interface:** A smooth and visually appealing UI for seamless navigation.  
- **Movie & Series Collection:** Browse through a vast collection of movies and TV series.  
- **Detailed Information:** Get insights about movies, including ratings, cast, and trailers.  
- **Filtering & Search:** Quickly find content with advanced filtering and search options.  
- **Watchlist Management:** Keep track of movies and shows you want to watch.

- **Framework:** Android (Kotlin)
- **Backend:** REST API / DASH )
- **API Integration:** TMDB API (for series details)
